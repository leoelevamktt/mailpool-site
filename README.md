# Mailpool — Site institucional

Landing page da plataforma Mailpool, criada com HTML e CSS, com uma estética minimalista baseada na identidade visual enviada pelo usuário.

## Como executar

Abra `index.html` no navegador ou execute `python3 -m http.server 8000` na pasta do projeto.

## Estrutura

- `index.html`: página institucional.
- `styles.css`: estilos responsivos.
- `assets/`: identidade visual.

## Observações

O site é uma apresentação institucional, não o painel operacional. As visualizações de interface são demonstrações ilustrativas e não exibem dados reais. Antes de disponibilizar cadastro ou acesso ao painel, configure os endereços reais da aplicação.
